# Advantage Testing — cinematic concept site

An **unofficial concept showcase** of a premium, scroll-driven cinematic website for
Advantage Testing — full-screen scroll-scrubbed "film" chapters rendered as frame
sequences on canvas, plus detailed content pages (Test Prep, Academic Tutoring,
Admissions, Online, Tutors, 22 location pages, Reviews, the AT Foundation, and News).

**Not affiliated with Advantage Testing.** Built as a design concept. Names, credentials,
headshots, reviews, addresses, and program content are public information drawn from
advantagetesting.com and public records; the cinematic visuals are AI-generated.

Local preview: `python3 serve.py 8960` → http://localhost:8960
